## ⚡ The Arsenal

This portfolio showcases a focus on **Generative AI APIs**, **LLM Integration**, and **Backend Architecture**.

- **AI/ML**: LangChain, LangGraph, CrewAI, RAG Systems, Fine-Tuning.
- **Backend & Infra**: FastAPI, Docker, Kubernetes, AWS, PostgreSQL, Vector Databases (Pinecone/Weaviate).
- **Frontend**: High-fidelity Vanilla JS integration with Spline 3D runtimes for immersive UI.

## 🌌 Architecture Highlights

The website is engineered for performance and visual impact:
- **3D Immersion**: Integrated interactive scenes from Spline.design using the `@splinetool/runtime` API.
- **Dynamic Design**: Minimalist dark-mode aesthetics with smooth micro-animations and custom HSL-tailored color palettes.
- **Production Ready**: Fully automated CI/CD pipeline via Netlify and GitHub.
